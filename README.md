# customtkinter-translator-tts

<p align="center">
  Aplicación de escritorio interactiva desarrollada en Python que permite traducir texto de español a inglés en tiempo real y reproducir la pronunciación en audio.

## 🚀 Características

- 🔄 **Traducción en Tiempo Real:** Integración con `deep_translator` para traducir de español a inglés.
- 🔊 **Reproducción de Audio (TTS):** Generación de voz mediante `gTTS` y reproducción asíncrona mediante `pygame.mixer`.
- 🎨 **Interfaz de Usuario Limpia:** Paneles dobles con manejo de estados (`enabled`/`disabled`) y placeholders interactivos.
